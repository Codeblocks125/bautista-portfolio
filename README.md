# William M. Bautista - Portfolio

Static portfolio website (HTML, CSS, JavaScript). No build step needed.

## Folder structure

```
index.html        Page content
css/style.css     All styles
js/main.js        Navbar highlight and scroll animations
images/           Photos and screenshots
```

## How to edit

- Text and links: edit `index.html`
- Colors, fonts, spacing: edit `css/style.css` (colors are at the top under `:root`)
- Replace a screenshot: upload a new image to `images/` with the same file name
